# AGENTS.md — docs

## Responsabilidad
Guardar documentación del producto, ideas y decisiones del evento.

## Documentos recomendados
- `PRODUCT.md`: objetivo y experiencia.
- `CHALLENGES.md`: banco de ideas antes de pasarlas a datos.
- `BRANDING.md`: nombre, colores, tipografía y tono.
- `DEPLOY.md`: instrucciones simples de publicación.

## Regla
La documentación debe describir el estado real del proyecto. No documentar funciones inexistentes como si ya estuvieran implementadas.
