# AGENTS.md — data

## Responsabilidad
Gestionar únicamente el contenido de los desafíos.

## Formato de desafío
Cada desafío debe tener como mínimo:
- `id`
- `text`

Opcionalmente:
- `category`
- `difficulty`
- `icon`

Ejemplo:
```js
{
  id: "photo-01",
  text: "Sacate una foto con tres personas que no estén en tu mesa.",
  category: "foto"
}
```

## Categorías sugeridas
- `baile`
- `social`
- `foto`
- `grupo`
- `random`

## Tono
- Divertido.
- Social.
- Respetuoso.
- Fácil de entender.
- Realizable durante una fiesta.

## Seguridad y convivencia
No incluir desafíos que:
- humillen a alguien;
- obliguen contacto físico;
- presionen situaciones románticas;
- impliquen alcohol, apuestas o conductas riesgosas;
- expongan información personal;
- filmen o fotografíen a alguien sin su consentimiento;
- puedan generar conflicto o incomodidad seria.

## Calidad
- Evitar desafíos casi idénticos.
- Frases breves.
- Una sola acción principal por desafío.
- Preferir desafíos que incentiven integración entre grupos.
