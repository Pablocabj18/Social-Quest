# AGENTS.md — CSS

## Responsabilidad
Definir la identidad visual y responsive de la experiencia.

## Diseño
- Mobile-first.
- Contenido principal centrado.
- Tarjeta de desafío como elemento protagonista.
- Botón principal muy visible.
- Acciones secundarias claramente diferenciadas.

## Tokens sugeridos
Definir variables CSS para:
- fondo
- superficie
- texto principal
- texto secundario
- acento
- radio
- sombra
- espacios

## Responsive
Diseñar primero para 360–430 px de ancho.
Luego adaptar para tablet y escritorio.

## Movimiento
- Transiciones de 150–300 ms.
- Entrada suave del desafío.
- Feedback visual al marcar `Cumplido`.
- Desactivar/reducir animaciones con `prefers-reduced-motion`.

## Evitar
- Texto demasiado pequeño.
- Exceso de gradientes.
- Efectos visuales pesados.
- Scroll innecesario en la pantalla principal.
- Botones de menos de ~44 px de alto.
